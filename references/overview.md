# 财商白话：财务自由书单总览

## 这套 skill 是什么

把 13 本财务自由/理财书里的可执行方法，蒸馏成一套“普通人能照着做”的财商工具包。它不做书摘，也不扮演作者；它只回答：**你现在该做什么，下一步怎么做。**

## 一条主线

1. **先看现状**：净资产、现金流、负债。
2. **再算目标**：财务保障 → 财务安全 → 财务自由。
3. **先防守**：应急金 + 保险，避免一次意外清零。
4. **再进攻**：低成本指数基金 + 资产配置 + 定投 + 再平衡。
5. **控消费**：拒绝生活方式通胀和面子税。
6. **提收入**：主业提效、副业验证、资产化。
7. **用 90 天计划**把以上动作变成系统。

## 不做什么

- 不推荐具体股票/基金/保险产品。
- 不承诺收益，不预测市场。
- 不替代法律、税务、医疗等专业意见。

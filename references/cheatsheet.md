# 决策规则速查 — 《财商白话：13 本财务自由书的可执行方法》

| 能力 | 一句话规则 |
|---|---|
| 财务自由数字：先把“要多少钱”算清楚 | 财务自由 = 被动收入 ≥ 生活支出；目标本金 = 年支出 ÷ 提取率（4% 法则约 25 倍）。 |
| 净资产体检：财富不是收入，是留下来的东西 | 财富 = 净资产 = 资产 − 负债；用年龄×收入÷10 做预期净资产对照。 |
| 现金流引擎：储蓄率才是普通人的第一杠杆 | 先付自己 + 分账户 + 收入涨先涨储蓄率；储蓄率决定本金积累速度。 |
| 负债分级与清债：先分清好债、坏债、要命的债 | 先分清高息消费债/中性债/生产性负债；高息优先，余钱 50% 还债 50% 储蓄。 |
| 应急金与保障：先别掉下去，再谈跑多快 | 先建 3～12 个月应急金，再配医疗/重疾/意外/寿险；先保障后理财。 |
| 指数基金定投：配置 + 定投 + 再平衡 | 用低成本宽基指数做资产配置，定投入场，估值加减仓，年度再平衡。 |
| 投资纪律：先活下来，再谈赚多少 | 能力圈 + 安全边际 + 逆向 + 不预测 + 不杠杆；先保证不下牌桌。 |
| 消费审查：别让面子税吃掉你的自由 | 区分必要/投资/面子支出；24 小时冷静期 + 年度大额预算 + 加薪先加储蓄。 |
| 收入升级：工资有上限，资产和杠杆没有 | 主业提效 → 副业验证 → 产品化/资产化 → 投资放大；用五戒律筛方向。 |
| 90 天财商行动方案：从知道到账上真的变了 | 30 天盘点止血、30 天建系统、30 天启动复盘；每周只做一件关键动作。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

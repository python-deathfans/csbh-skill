# 应急金与保障：先别掉下去，再谈跑多快

## R — 原文 (Reading)

> 紧急备用金的金额建议能够保证6~12个月的家庭生活开支，包括基本生活费用、贷款、购物消费等所有开支。
>
> — 也小谈《工薪族财务自由说明书》保险篇

> 整个财务自由计划可以概括为：开源、节流、加固，分别对应着积累本金、投资和保险。
>
> — 也小谈《工薪族财务自由说明书》第一章

> 时刻在保险柜中存放一笔不可动用的储备金。
>
> — 博多·舍费尔《财务自由之路》

## I — 方法论骨架 (Interpretation)

财务自由是“进攻”，应急金和保险是“防守”。没有防守，一次失业、大病或意外就能把多年积累清零。

**应急金**

- 金额：3～12 个月必要支出。单身、双职工、收入稳定取低值；有房贷、育儿、单收入家庭取高值。
- 位置：货币基金、银行活期/短期存款、国债逆回购等低风险、T+0/T+1 可取的地方。
- 纪律：只用于失业、医疗、突发维修等“真应急”，不用于旅行、换手机、抄底。

**保障四件套**

1. **医疗险**：报销大额住院/手术费用，解决“因病致贫”。
2. **重疾险**：确诊后一次性给付，补偿收入中断和康复费用。
3. **意外险**：覆盖意外身故/伤残/医疗，杠杆高、价格低。
4. **寿险**：家庭经济支柱必备，保额覆盖房贷、子女教育、父母赡养。

原则：**先保障、后理财；先保额、后保费；先大人、后小孩。** 保费控制在家庭年收入的 5%～10%，不要为了“返还”买昂贵的理财型保险。

## A1 — 书中的应用 (Past Application)

### 案例 1：没有 5000 欧元现金的债务人
- **问题**：债台高筑先生有 17.5 万欧元债务，却没有 5000 欧元现金。
- **方法**：作者让他先留一笔不可动用的储备金，再谈还债。
- **结论**：没有现金缓冲，80% 的精力会被琐事消耗。
- **结果**：先有安全感，才能稳定创造收入。

### 案例 2：保险是“加固”而不是“收益”
- **问题**：很多人把保险当投资，追求返还和分红。
- **方法**：工薪族作者把保险归入“加固”，与开源、节流并列。
- **结论**：保险的作用是守住资产，不是提高收益率。
- **结果**：先配齐医疗、重疾、意外、寿险，再考虑理财型产品。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. “应急金要存几个月？”
2. “要不要买保险？先买哪个？”
3. “公司裁员/生病了，房贷怎么办？”
4. “保险代理人推荐分红险，要不要买？”
5. “有 5 万块，先投资还是先留备用金？”

### 语言信号

- “应急金 / 备用金 / 6 个月 / 12 个月”
- “医疗险 / 重疾险 / 意外险 / 寿险”
- “因病致贫 / 裁员 / 断供”

### 与相邻 skill 的区分

- 与 `debt-clearing` 的区别：应急金优先于清债，不能被清债掏空。
- 与 `index-investing` 的区别：应急金不追求收益，追求随时可用。

## E — 可执行步骤 (Execution)

1. **算必要月支出**
   - 房租/房贷、吃饭、交通、保险、育儿、父母赡养、最低还款。
   - 完成标准：得到一个“失业也必须花”的月支出数字。

2. **定应急金目标**
   - 目标 = 必要月支出 × 3～12 个月。
   - 完成标准：写下目标金额和选择月数的理由。

3. **建应急金账户**
   - 单独开一个货币基金/存款账户，不绑日常支付。
   - 完成标准：自动转账开始，3 个月内达到第一档（1 个月）。

4. **做保障盘点**
   - 列出社保、医保、公司团险、已有商业险；标出缺口。
   - 完成标准：四类保障各写“已有/缺口/保额”。

5. **先补大人和支柱**
   - 医疗险 + 意外险优先，重疾/寿险按家庭责任补。
   - 完成标准：家庭经济支柱的保额覆盖房贷 + 3～5 年家庭支出。

6. **每年复核**
   - 收入、房贷、孩子、父母健康变化时更新。
   - 完成标准：日历提醒，保单和受益人信息检查一遍。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 具体保险产品对比、健康告知、理赔纠纷：建议找持牌经纪人/专业人士。
- 已有严重疾病或高风险职业：投保条件复杂，不要自行判断。
- 应急金不要拿去买股票、封闭基金、长期理财。

### 作者在书中警告的失败模式

- 把保险当投资，保费过高，挤占储蓄和投资。
- 只给孩子买，大人“裸奔”。
- 应急金放在随时可刷的账户，最后被消费掉。

### 作者的盲点 / 时代局限

- 中国社保/医保体系与美国不同，商保配置需按本地政策调整。
- 书中部分保险建议基于欧洲市场，产品和费率不能直接套用。

### 容易混淆的邻近方法论

- `cashflow-engine`：应急金来自现金流，先有储蓄率才有应急金。
- `debt-clearing`：清债前先留缓冲，避免再次借贷。

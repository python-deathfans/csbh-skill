# 指数基金定投：普通人用“配置 + 定投 + 再平衡”慢慢变富

## R — 原文 (Reading)

> 这就是定投指数基金的好处。我们只需每个月拿出一点点时间，进行指数基金的定投，就可以获得这样的好收益。
>
> — 银行螺丝钉《定投十年财务自由》

> 配置50%的股票资产+50%的类现金资产，并在后续的投资组合管理中使用最简单的再平衡策略。
>
> — 《傻瓜式投资》推荐序（50:50 法则）

> 面对难以预判的事情，最好的办法就是不预判。关于上述问题，最科学的解决方案就是——动态再平衡。
>
> — 刘诚《投资要义》第三章

> 买基“三步曲”：确定投资目标、选择优秀基金和掌握投资方法。
>
> — 季凯帆《解读基金》第一章

## I — 方法论骨架 (Interpretation)

普通人没有选股优势，但可以用一套“笨办法”获得市场平均收益：

1. **先定目标与期限**：这笔钱几年不用？能承受多大回撤？3 年内要用的钱不进场。
2. **做资产配置**：股票类（宽基指数）与债券/现金类按比例搭配。经典 50:50，也可按风险承受力做 60:40、70:30。
3. **用低成本宽基指数**：沪深 300、中证 500、标普 500、全球市场指数等，费率越低越好，避免单一行业押注。
4. **定投**：每月固定日期买入，平滑成本；收入稳定后可从“定期定额”升级为“定期不定额”——越低估买越多。
5. **再平衡**：每年或偏离目标比例 5～10 个百分点时，卖高买低，恢复原比例。它强制你“高抛低吸”，不靠预测。
6. **看估值，不追热点**：低估区域多买，高估区域少买/止盈；估值不是精确择时，而是控制情绪和仓位。

一句话：**用配置决定风险，用定投解决入场，用再平衡解决卖出。**

## A1 — 书中的应用 (Past Application)

### 案例 1：50:50 的“傻瓜式”组合
- **问题**：普通散户不会选股、不会择时，怎么在市场里活下去？
- **方法**：50% 股票指数 + 50% 类现金资产，每年再平衡一次。
- **结论**：放弃预测，用规则战胜情绪。
- **结果**：长期跑赢大多数频繁交易的散户。

### 案例 2：螺丝钉的估值定投
- **问题**：同样是定投，为什么有人收益更高？
- **方法**：在股市低估时开始定投，低估越多买越多；高估时减少买入或止盈。
- **结论**：定投不是“无脑买”，估值是收益放大器。
- **结果**：长期业绩优于不看估值的定投。

### 案例 3：解读基金“三步曲”
- **问题**：基金几千只，怎么选？
- **方法**：先定投资目标，再选优秀基金，最后掌握投资方法。
- **结论**：先想清楚“为什么买、买多久、能亏多少”，再谈产品。
- **结果**：把“买基金”从跟风变成一套流程。

## E — 可执行步骤 (Execution)

1. **确定钱的性质**
   - 写清楚：这笔钱多久不用、最大可承受回撤、是否影响生活。
   - 完成标准：3 年内要用的钱被排除在股票类投资之外。

2. **定资产配置**
   - 保守 30/70，稳健 50/50，进取 70/30（股票/债券现金）。
   - 完成标准：写下一个比例，并说明理由。

3. **选低成本宽基**
   - 优先宽基、费率低、规模大、跟踪误差小；不押单一行业。
   - 完成标准：选出 1～3 只标的，记录费率。

4. **设定投计划**
   - 固定日期、固定金额；发薪日后 1～3 天自动扣款。
   - 完成标准：连续执行 3 个月，不因涨跌停投。

5. **加估值规则**
   - 低估区正常/加倍投，高估区减半/暂停，极端高估分批止盈。
   - 完成标准：写下估值来源和触发阈值。

6. **年度再平衡**
   - 每年一次，或偏离目标 5～10 个百分点时再平衡。
   - 完成标准：记录买卖金额，恢复目标比例。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 3 年内要用的钱（买房首付、结婚、学费）不要投入高波动资产。
- 不要用杠杆、消费贷、信用卡套现去定投。
- 不要问“哪只基金明天涨”，本卡不做短期预测。

### 作者在书中警告的失败模式

- 牛市高位一把梭，熊市恐慌割肉。
- 追上年冠军基金、追热点行业。
- 频繁交易，费用和情绪把收益吃掉。
- 定投后不管理，永远不止盈/再平衡。

### 作者的盲点 / 时代局限

- 书中的估值方法和指数品种基于特定市场阶段，历史收益不代表未来。
- 中国市场的行业结构、政策变化快，宽基也要做地域/行业分散。
- 4% 提取率与定投收益不能简单等同，退休后要留更厚的安全垫。

### 容易混淆的邻近方法论

- `investing-discipline`：解决“怎么不犯错”；本卡解决“怎么搭组合”。
- `emergency-shield`：应急金不参与定投。

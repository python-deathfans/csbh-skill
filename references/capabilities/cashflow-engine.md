# 现金流引擎：储蓄率才是普通人的第一杠杆

## R — 原文 (Reading)

> 我坚定地说：“我已经想好该怎么分配我的钱了，我也要把50%的收入变成我的‘鹅’，40%放入我的梦想储蓄罐，剩下的10%用来花。”
>
> — 博多·舍费尔《小狗钱钱》第十一章

> 假如A原收入5000元，每个月储蓄500元，那么储蓄率为10%。如果A工资涨了5000元，其中一半用来增加储蓄，则每月储蓄3000元，储蓄率就变成了30%。
>
> — 也小谈《工薪族财务自由说明书》第一章

> 只有当你将金钱留存下来之后，你才会变得富有。
>
> — 博多·舍费尔《财务自由之路》

## I — 方法论骨架 (Interpretation)

普通人控制不了市场，但能控制**储蓄率**。储蓄率 = 每月存下的钱 ÷ 税后收入。它同时决定三件事：本金积累速度、财务自由门槛、抗风险能力。

书里反复出现三个动作：

1. **先付自己**：工资到账先转储蓄/投资，剩下的再花；不是“花剩了再存”。
2. **分账户**：把收入分成“鹅（长期投资）”“梦想（大额目标）”“日常（必要开销）”三份。小狗钱钱用 50/40/10，成年人可按 50/30/20 或 60/20/20 调整。
3. **收入涨，储蓄率先涨**：加薪时先把新增收入的一半以上转进储蓄，避免生活方式同步膨胀。

一个可执行的比例：

- 50% 必要支出（房租/房贷、吃饭、交通、保险）
- 30% 生活质量（娱乐、旅行、社交）
- 20% 储蓄与投资（先付自己）

如果现在做不到 20%，先做到 5%～10%，再每月提高 1 个百分点。关键是自动化，不靠意志力。

## A1 — 书中的应用 (Past Application)

### 案例 1：吉娅的 50/40/10
- **问题**：想买电脑、去美国，又想帮爸妈还债，零花钱不够。
- **方法**：50% 变成“鹅”，40% 放进梦想储蓄罐，10% 当零花钱。
- **结论**：同一笔钱可以同时服务于长期、梦想和当下。
- **结果**：吉娅靠分配和赚钱，逐步实现了目标。

### 案例 2：加薪后储蓄率反而下降
- **问题**：A 原收入 5000，存 500，储蓄率 10%；涨薪到 10000 后，仍只存 500。
- **方法**：计算储蓄率变化。
- **结论**：储蓄率从 10% 降到 5%，加薪没有变成财富。
- **结果**：如果新增收入的一半转储蓄，储蓄率可升到 30%，储蓄额增加 5 倍。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. “月光族怎么开始存钱？”
2. “工资涨了，为什么还是存不下？”
3. “每个月该存多少比例？”
4. “要不要记账/怎么做预算？”
5. “先存钱还是先还债？”

### 语言信号

- “月光 / 存不下钱 / 储蓄率”
- “工资到账就没了”
- “50/30/20 / 先付自己 / 自动转账”

### 与相邻 skill 的区分

- 与 `spending-audit` 的区别：本卡建“存钱系统”，消费卡砍“漏点”。
- 与 `debt-clearing` 的区别：有高息债时，本卡与清债卡配合，通常保留一半余钱储蓄、一半还债。

## E — 可执行步骤 (Execution)

1. **算当前储蓄率**
   - 过去 3 个月（税后收入 − 总支出）÷ 税后收入。
   - 完成标准：得到一个百分比，并写下最大三类支出。

2. **设“先付自己”自动转账**
   - 发薪日次日自动转入独立储蓄/投资账户。
   - 完成标准：转账金额 ≥ 当前储蓄率，且连续执行 3 个月。

3. **分三个账户**
   - 鹅账户（长期投资）、梦想账户（1～3 年目标）、日常账户（必要开销）。
   - 完成标准：三个账户开好，比例写下来。

4. **做月度预算**
   - 用“年度开支 ÷ 12”而不是只看当月，避免保险/学费/旅行漏算。
   - 完成标准：预算覆盖固定支出、浮动支出、年度大额支出。

5. **加薪规则**
   - 新增税后收入至少 50% 进入鹅账户。
   - 完成标准：下次加薪时执行，并记录储蓄率变化。

6. **每月 10 分钟复盘**
   - 完成标准：检查储蓄率、超支项、下月调整，不追求完美。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 收入不稳定或低于基本生活线：先稳收入/求助，不要硬设高储蓄率。
- 有高息消费债：不要把所有余钱都存起来而忽略高息；按 `debt-clearing` 的 50/50 规则处理。
- 不要把“储蓄”当成“投资”：存款安全但难抗通胀，长期资金要进入资产配置。

### 作者在书中警告的失败模式

- 支出随收入同步增长，永远存不下钱。
- 只靠意志力记账，几个月后放弃；要用自动化。
- 为了储蓄牺牲健康、关系和成长，最后反弹。

### 作者的盲点 / 时代局限

- 50/40/10 是童话里的儿童比例，成年人房租/育儿压力更大，需要按现实调整。
- 中国一线城市住房成本高，必要支出比例可能远超 50%，不要机械套比例。

### 容易混淆的邻近方法论

- `spending-audit`：砍支出；本卡建储蓄系统。两者一进一出。
- `emergency-shield`：先建应急金，再提高长期投资比例。
